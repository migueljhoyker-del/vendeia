FAQ

Preguntas frecuentes.

¿VendeIA inventa características? +

El sistema está diseñado para utilizar la información proporcionada por el vendedor y los elementos que pueda identificar visualmente. Debes revisar siempre el anuncio antes de publicarlo.

¿Puedo subir fotografías? +

Sí. Puedes añadir hasta seis fotografías del producto. Las imágenes se comprimen en el navegador antes de enviarse para mantener el proceso ligero.

¿Qué plataformas son compatibles? +

La primera versión está preparada para generar anuncios generales y adaptar el estilo a Wallapop, Vinted, Facebook Marketplace y eBay.

¿Necesito saber de inteligencia artificial? +

No. La interfaz está diseñada para que únicamente tengas que introducir la información de tu producto.

¿La fotografía sustituye a la información escrita? +

No. Las fotografías son una fuente adicional de información. Los datos escritos por el vendedor siguen siendo fundamentales.
